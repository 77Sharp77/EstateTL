# 🏡 Kalicaa Villa - Estate Management & Billing System (PHP App)

Aplikasi Web Manajemen Tagihan Estate, Listrik, Air PDAM, IPL Kawasan, Kontrak SKP Villa, SPK Kontraktor, dan Titipan Dana BWJ/TLLI berbasis PHP 8.2+ dan MySQL / MariaDB.

---

## 📌 Domain & Server Anda:
* **Domain Utama:** `docutrack7.web.id`
* **Rekomendasi Subdomain:** `estate.docutrack7.web.id`
* **Username cPanel:** `docutrac`
* **Database MySQL:** `docutrac_estate.tanjunglesung.com`

---

## ⚡ Solusi Error NXDOMAIN:
Jangan gunakan `estate.tanjunglesung.com` karena domain `tanjunglesung.com` bukan milik akun hosting Anda.
Gunakanlah subdomain di bawah domain utama Anda:
👉 **`estate.docutrack7.web.id`** (100% Gratis dan langsung aktif tanpa beli domain baru).
